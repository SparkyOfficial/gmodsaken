
Для тестирования геймплея без других игроков используйте систему тестовых ботов:


**Добавить бота:**
```
gmodsaken_addbot
```
или в чате:
```
!bot
!addbot
```

**Удалить всех ботов:**
```
gmodsaken_removebot
```
или в чате:
```
!removebot
!removebots
```

**Информация о ботах:**
```
gmodsaken_botinfo
```

### Как работают тестовые боты

- Боты создаются как NPC (граждане)
- Они появляются на случайных точках спавна
- Имеют 100 HP
- Помечены как тестовые боты
- Автоматически удаляются при смене карты

### Примечания

- **ВАЖНО:** Тестовые боты НЕ учитываются системой как игроки
- Для тестирования в одиночку минимальное количество игроков изменено на 1
- Вы можете тестировать геймплей один, без ботов
- Боты создаются как NPC и могут использоваться для визуального тестирования
- Для полноценного тестирования рекомендуется играть с реальными игроками

### Тестирование в одиночку

Теперь вы можете тестировать мод в одиночку:

1. Зайдите на сервер
2. Выберите персонажа (F4)
3. Подождите 30 секунд или используйте `!forcestart`
4. Вы станете выжившим и сможете тестировать механики

### Альтернативные методы тестирования

1. **Локальный сервер с друзьями:**
   - Запустите локальный сервер
   - Пригласите друзей через Steam

2. **Режим одиночной игры:**
   - Используйте `sv_cheats 1` для отладки
   - Тестируйте механики в одиночку

3. **Выделенный тестовый сервер:**
   - Настройте тестовый сервер
   - Используйте для регулярного тестирования

## Настройки стамины

Текущие настройки стамины оптимизированы для динамичного геймплея:

- **Максимальная стамина:** 100
- **Время бега до истощения:** 9 секунд
- **Скорость восстановления:** 2.5 (очень быстрое)
- **Стоимость прыжка:** 5
- **Стоимость атаки:** 3

### Команды для управления стаминой

**Проверить стамину:**
```
gmodsaken_stamina
```

**Отключить стамину (для отладки):**
```
gmodsaken_disable_stamina
```

**Включить стамину:**
```
gmodsaken_enable_stamina
```

## Полезные команды для тестирования

**Принудительно начать раунд:**
```
gmodsaken_force_start
```
или `!forcestart` в чате (только для администраторов)

**Принудительно завершить раунд:**
```
gmodsaken_force_end
```
или `!forceend` в чате

**Запустить режим LMS:**
```
gmodsaken_force_lms
```

**Отладка состояния игры:**
```
gmodsaken_debug_state
```

**Отладка ролей:**
```
gmodsaken_debug_roles
```

## Требования

- Garry's Mod (последняя версия)
- Права администратора на сервере
- Карта с точками спавна (info_player_start или info_player_deathmatch)
