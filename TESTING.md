# Руководство по тестированию GModsaken

## ✅ САМЫЙ ПРОСТОЙ СПОСОБ - Встроенные боты Garry's Mod

Garry's Mod имеет встроенную поддержку ботов! Просто используйте:

**Добавить бота:**
```
bot
```
Введите в консоли (клиентской или серверной)

**Удалить бота:**
```
bot_kick
```

**Удалить всех ботов:**
```
bot_kick_all
```

**Настройки ботов:**
```
bot_quota 4          // Установить количество ботов
bot_join_team red    // Боты присоединяются к команде
bot_zombie 1         // Боты не двигаются (для тестирования)
```

## Тестирование в одиночку (БЕЗ ботов)

Минимальное количество игроков изменено на 1, поэтому вы можете тестировать мод в одиночку:

1. Зайдите на сервер
2. Выберите персонажа (F4)
3. Подождите 30 секунд или используйте `!forcestart` в чате
4. Вы станете выжившим и сможете тестировать механики

## Альтернатива - NPC боты (для визуального тестирования)

Эти боты НЕ учитываются как игроки, но могут использоваться для визуального тестирования:

**Добавить NPC бота:**
```
gmodsaken_addbot
```

**Удалить всех NPC ботов:**
```
gmodsaken_removebot
```

**Информация о NPC ботах:**
```
gmodsaken_botinfo
```

## Настройки стамины

Текущие настройки стамины оптимизированы для динамичного геймплея:

- **Максимальная стамина:** 100
- **Время бега до истощения:** 9 секунд
- **Скорость восстановления:** 2.5 (очень быстрое)
- **Стоимость прыжка:** 5
- **Стоимость атаки:** 3

### Команды для управления стаминой

**Проверить стамину:**
```
gmodsaken_stamina
```

**Отключить стамину (для отладки):**
```
gmodsaken_disable_stamina
```

**Включить стамину:**
```
gmodsaken_enable_stamina
```

## Полезные команды для тестирования

**Принудительно начать раунд:**
```
gmodsaken_force_start
```
или `!forcestart` в чате (только для администраторов)

**Принудительно завершить раунд:**
```
gmodsaken_force_end
```
или `!forceend` в чате

**Запустить режим LMS:**
```
gmodsaken_force_lms
```

**Отладка состояния игры:**
```
gmodsaken_debug_state
```

**Отладка ролей:**
```
gmodsaken_debug_roles
```

## Требования

- Garry's Mod (последняя версия)
- Права администратора на сервере
- Карта с точками спавна (info_player_start или info_player_deathmatch)

## Быстрый старт тестирования

1. **Запустите локальный сервер**
2. **Добавьте ботов:** введите `bot` в консоли несколько раз
3. **Выберите персонажа:** нажмите F4
4. **Начните раунд:** `!forcestart` в чате
5. **Тестируйте!**
